## 快速开始

### 1. 运行服务端

```bash
node 03-NodeJS服务端示例.js
```

### 2. 打开浏览器

访问 http://localhost:3000/

### 3. 点击"连接 SSE"按钮

观察接收到的实时消息。

## SSE 数据格式速查

```
data: 消息内容          # 必填
id: 事件ID             # 可选，用于断线重连
event: 事件类型        # 可选，自定义事件名
retry: 毫秒数          # 可选，重连等待时间
: 注释                 # 可选，会被忽略
```

消息之间用空行分隔：`\n\n`
