# JavaScript 可迭代对象的消费方式

## 概念澄清：可迭代对象 ≠ 迭代器

| 概念 | 协议 | 核心方法 | 特性 |
|------|------|---------|------|
| **可迭代对象（Iterable）** | 可迭代协议 | `[Symbol.iterator]()` | **可重复消费**，每次调用返回一个**新**的迭代器 |
| **迭代器（Iterator）** | 迭代器协议 | `next()` | **一次性消费**，消费完即耗尽 |

```javascript
// 可迭代对象：数组、字符串、Set、Map、NodeList、arguments 等
const iterable = [1, 2, 3];

// 可以多次消费
for (const v of iterable) console.log(v); // 1, 2, 3
for (const v of iterable) console.log(v); // 1, 2, 3  ← 仍然有效！

// 而迭代器只能消费一次
const iterator = iterable[Symbol.iterator]();
for (const v of iterator) console.log(v); // 1, 2, 3
for (const v of iterator) console.log(v); // (无输出，已耗尽)
```

## 一、语言层面内置消费（语法级）

### 1. for...of 循环（最常用）

```javascript
const arr = [1, 2, 3];

for (const value of arr) {
    console.log(value); // 1, 2, 3
}
```

**特点：**
- 自动调用 `[Symbol.iterator]()` 获取迭代器
- 自动调用 `next()` 直到 `done: true`
- 支持 `break`、`continue`、`return`、`throw` 提前退出
- 会触发迭代器的 `return()` 方法（如果存在）进行清理

### 2. 解构赋值

```javascript
const arr = [1, 2, 3, 4, 5];

// 完全解构
const [a, b, c] = arr;
console.log(a, b, c); // 1, 2, 3

// 剩余元素
const [x, ...rest] = arr;
console.log(x, rest); // 1, [2, 3, 4, 5]

// 默认值
const [m = 10, n = 20] = [1];
console.log(m, n); // 1, 20
```

### 3. 展开运算符（Spread）

```javascript
const arr = [1, 2, 3];

// 数组展开
const copy = [...arr]; // [1, 2, 3]

// 函数参数展开
function sum(a, b, c) { return a + b + c; }
console.log(sum(...arr)); // 6

// 合并
const merged = [0, ...arr, 4]; // [0, 1, 2, 3, 4]
```

### 4. Promise.all / Promise.race / Promise.allSettled / Promise.any

```javascript
// 接受可迭代对象作为参数
const promises = [
    fetch('/api/1'),
    fetch('/api/2'),
    fetch('/api/3')
];

Promise.all(promises).then(results => {
    console.log('全部完成', results);
});

// Set 也是可迭代对象
Promise.race(new Set(promises)).then(first => {
    console.log('最快的一个', first);
});
```

### 5. yield* 委托生成器

```javascript
function* inner() {
    yield 1;
    yield 2;
    yield 3;
}

function* outer() {
    yield 0;
    yield* inner(); // 委托给可迭代对象
    yield 4;
}

console.log([...outer()]); // [0, 1, 2, 3, 4]
```

## 二、API 层面消费

### 1. Array.from()

```javascript
const set = new Set([1, 2, 3]);

// 转为数组
const arr = Array.from(set); // [1, 2, 3]

// 带映射函数
const doubled = Array.from(set, x => x * 2); // [2, 4, 6]
```

### 2. Map / Set / WeakMap / WeakSet 构造函数

```javascript
const iterable = [[1, 'a'], [2, 'b'], [3, 'c']];

// Map 接受键值对可迭代对象
const map = new Map(iterable);
console.log(map.get(1)); // 'a'

// Set 接受任意可迭代对象
const set = new Set([1, 2, 2, 3]);
console.log(set); // Set(3) { 1, 2, 3 }
```

### 3. Object.fromEntries()

```javascript
const entries = new Map([['a', 1], ['b', 2]]);
const obj = Object.fromEntries(entries);
console.log(obj); // { a: 1, b: 2 }
```

### 4. 数组方法（需先转换）

```javascript
const set = new Set([1, 2, 3]);

// 方式1：Array.from
Array.from(set).map(x => x * 2);

// 方式2：展开
[...set].filter(x => x > 1);

// 方式3：直接使用 map/filter（Set 不支持，仅数组支持）
```

## 三、手动消费（通过迭代器）

### 1. 显式调用 next()

```javascript
const iterable = 'abc';
const it = iterable[Symbol.iterator]();

console.log(it.next()); // { value: 'a', done: false }
console.log(it.next()); // { value: 'b', done: false }
console.log(it.next()); // { value: 'c', done: false }
console.log(it.next()); // { value: undefined, done: true }
```

### 2. while 循环手动消费

```javascript
const iterable = [1, 2, 3];
const it = iterable[Symbol.iterator]();

while (true) {
    const { value, done } = it.next();
    if (done) break;
    console.log(value);
}
```

### 3. 传递给接受迭代器的函数

```javascript
function consume(iterator) {
    while (true) {
        const { value, done } = iterator.next();
        if (done) break;
        console.log(value);
    }
}

consume([1, 2, 3][Symbol.iterator]());
```

## 四、自定义可迭代对象的消费

### 1. 对象实现 [Symbol.iterator]

```javascript
const myIterable = {
    data: [10, 20, 30],
    [Symbol.iterator]() {
        let index = 0;
        const data = this.data;
        return {
            next() {
                if (index < data.length) {
                    return { value: data[index++], done: false };
                }
                return { value: undefined, done: true };
            }
        };
    }
};

// 可以被任何消费可迭代对象的语法使用
console.log([...myIterable]);           // [10, 20, 30]
for (const v of myIterable) console.log(v); // 10, 20, 30
const [a, b] = myIterable;              // a=10, b=20
```

### 2. 生成器函数（最简实现）

```javascript
const myIterable = {
    *[Symbol.iterator]() {
        yield 'a';
        yield 'b';
        yield 'c';
    }
};

console.log([...myIterable]); // ['a', 'b', 'c']
```

## 五、异步可迭代对象的消费

### 1. for await...of

```javascript
async function* fetchPages() {
    let page = 1;
    while (page <= 3) {
        const res = await fetch(`/api/page/${page}`);
        yield await res.json();
        page++;
    }
}

// 消费异步可迭代对象
(async () => {
    for await (const data of fetchPages()) {
        console.log(data);
    }
})();
```

### 2. 手动消费异步迭代器

```javascript
async function consumeAsync() {
    const asyncIterable = fetchPages();
    const it = asyncIterable[Symbol.asyncIterator]();

    console.log(await it.next()); // { value: data1, done: false }
    console.log(await it.next()); // { value: data2, done: false }
    console.log(await it.next()); // { value: data3, done: false }
    console.log(await it.next()); // { value: undefined, done: true }
}

consumeAsync();
```

## 六、消费方式全景对比

| 消费方式 | 适用对象 | 自动完成 | 可中断 | 可重复 | 典型场景 |
|---------|---------|---------|--------|--------|---------|
| `for...of` | 可迭代对象 | ✅ | ✅ | ✅ | **通用遍历（推荐）** |
| 解构赋值 | 可迭代对象 | ❌ | ❌ | ✅ | 取前 N 个值 |
| 展开运算符 `...` | 可迭代对象 | ✅ | ❌ | ✅ | 转数组 / 合并 |
| `Array.from()` | 可迭代对象 | ✅ | ❌ | ✅ | 转数组（带映射） |
| `yield*` | 可迭代对象 | ✅ | ✅ | ✅ | 生成器委托 |
| `Promise.all/race` | 可迭代对象 | ✅ | ❌ | ✅ | 并发 Promise |
| `new Map/Set()` | 可迭代对象 | ✅ | ❌ | ✅ | 集合构造 |
| `Object.fromEntries` | 可迭代对象 | ✅ | ❌ | ✅ | 转对象 |
| 手动 `next()` | **迭代器** | ❌ | ✅ | ❌ | 精确控制 |
| `for await...of` | 异步可迭代对象 | ✅ | ✅ | ✅ | 异步流式数据 |

## 七、内置可迭代对象清单

JavaScript 中以下对象原生实现了可迭代协议：

| 对象 | 默认迭代行为 | 备注 |
|------|------------|------|
| `Array` | 元素值 | `entries()`、`keys()`、`values()` |
| `String` | Unicode 码点 | 正确处理代理对 |
| `Set` | 元素值 | 按插入顺序 |
| `Map` | `[key, value]` 数组 | `entries()`、`keys()`、`values()` |
| `TypedArray` | 元素值 | `Int8Array` 等 |
| `arguments` | 参数值 | 函数内置 |
| `NodeList` | DOM 节点 | `querySelectorAll` 返回 |
| `Generator` | yield 的值 | 生成器对象本身也是迭代器 |
| `URLSearchParams` | `[name, value]` | 查询参数 |

## 八、最佳实践

### 1. 优先使用 for...of

```javascript
// ✅ 推荐
for (const item of array) { /* ... */ }

// ❌ 不推荐（除非需要索引）
for (const item of array.entries()) {
    console.log(item); // [0, 'a'], [1, 'b']
}
```

### 2. 转换为数组以使用函数式方法

```javascript
// Set 没有map/filter，先转数组
const set = new Set([1, 2, 3]);
const result = [...set].map(x => x * 2).filter(x => x > 2);
```

### 3. 注意 Map 的默认迭代

```javascript
const map = new Map([['a', 1], ['b', 2]]);

// 默认迭代 entries
for (const item of map) {
    console.log(item); // ['a', 1], ['b', 2]
}

// 解构键值
for (const [key, value] of map) {
    console.log(key, value);
}
```

### 4. 不要混淆 for...in 和 for...of

```javascript
const arr = ['a', 'b', 'c'];

// for...in 遍历键（索引）—— 包括原型链上的可枚举属性
for (const i in arr) console.log(i); // '0', '1', '2'

// for...of 遍历值
for (const v of arr) console.log(v); // 'a', 'b', 'c'
```

## 九、总结

1. **可迭代对象** 的核心标志：实现了 `[Symbol.iterator]()` 方法
2. **每次消费都创建新的迭代器**，因此可重复消费
3. **消费方式三巨头**：`for...of`、展开运算符 `[...]`、解构赋值
4. **API 转换**：`Array.from`、`new Map/Set`、`Object.fromEntries`
5. **异步版本**：`for await...of` 配合 `Symbol.asyncIterator`
6. **推荐首选 `for...of`**，简洁安全且语义清晰
