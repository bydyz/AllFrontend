# 三数之和最接近 (3Sum Closest)

## 📝 题目描述

给你一个整数数组 `nums` 和一个整数 `target`，请你从中找出三个整数，使得它们的和与 `target` 最接近。返回这三个数的和。

---

## 📊 示例

### 示例 1

**输入：** nums = [-1, 2, 1, -4], target = 1

**输出：** 2

**解释：**

- 最接近目标的和是 2（-1 + 2 + 1 = 2）
- 与目标值的差为 |2 - 1| = 1

---

### 示例 2

**输入：** nums = [0, 0, 0], target = 1

**输出：** 0

**解释：**

- 最接近目标的和是 0（0 + 0 + 0 = 0）
- 与目标值的差为 |0 - 1| = 1

---

## 🎯 提示

- `3 <= nums.length <= 500`
- `-1000 <= nums[i] <= 1000`
- `-10^4 <= target <= 10^4`
