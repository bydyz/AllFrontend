# 二进制矩阵中的最短路径 (Shortest Path in Binary Matrix)

## 📝 题目描述

给你一个 `n x n` 的二进制矩阵 `grid`，返回矩阵中 **最短清晰路径** 的长度。如果不存在清晰路径，返回 `-1`。

二进制矩阵中的清晰路径是从 **左上角** 单元格（即 `(0, 0)`）到 **右下角** 单元格（即 `(n - 1, n - 1)`）的路径，满足：

- 路径中所有访问过的单元格的值都是 `0`
- 路径中所有相邻单元格在 **8个方向上** 相连（即它们是不同的单元格，并且它们共享一条边或一个角）

**清晰路径的长度** 是该路径中访问过的单元格数。

---

## 📊 示例

### 示例 1

**输入：**

```
grid = [[0,1],[1,0]]
```

**输出：**

```
2
```

### 示例 2

**输入：**

```
grid = [[0,0,0],[1,1,0],[1,1,0]]
```

**输出：**

```
4
```

### 示例 3

**输入：**

```
grid = [[1,0,0],[1,1,0],[1,1,0]]
```

**输出：**

```
-1
```

---

## 🎯 提示

- `n == grid.length`
- `n == grid[i].length`
- `1 <= n <= 100`
- `grid[i][j]` 为 `0` 或 `1`
