# 砖墙 (Brick Wall)

## 📝 题目描述

有一面砖墙，它由 `n` 行砖块组成，每行砖块的高度为 1。每行的砖块长度可能不同，但所有行的总宽度相同。

画一条从墙的顶部到底部的垂直线，穿过最少的砖块。如果线穿过砖块的边缘，则不算穿过该砖块。你不能沿墙的左右边缘画线（显然这种情况不会穿过任何砖块）。

给你一个二维数组 `wall`，其中 `wall[i]` 是第 `i` 行砖块的宽度列表。请你返回画出这条线后，穿过的砖块的最小数量。

---

## 📊 示例

### 示例 1

**输入：**

```
wall = [[1,2,2,1],[3,1,2],[1,3,2],[2,4],[3,1,2],[1,3,1,1]]
```

**输出：**

```
2
```

### 示例 2

**输入：**

```
wall = [[1],[1],[1]]
```

**输出：**

```
3
```

---

## 🎯 提示

- `n == wall.length`
- `1 <= n <= 10^4`
- `1 <= wall[i].length <= 10^4`
- `1 <= sum(wall[i].length) <= 2 * 10^4`
- `sum(wall[i])` 对每行 `i` 都相同
- `1 <= wall[i][j] <= 2^31 - 1`
