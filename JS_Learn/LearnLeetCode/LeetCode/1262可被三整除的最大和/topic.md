# 1262 可被三整除的最大和

[LeetCode 链接](https://leetcode.cn/problems/greatest-sum-divisible-by-three/)

## 题目描述
给你一个整数数组 nums，请你找出并返回能被三整除的元素最大和。

## 示例

### 示例 1
输入：nums = [3,6,5,1,8]
输出：18
解释：选出数字 3, 6, 1 和 8，它们的和是 18（可被 3 整除的最大和）。

### 示例 2
输入：nums = [4]
输出：0
解释：4 不能被 3 整除，所以无法选出数字，返回 0。

### 示例 3
输入：nums = [1,2,3,4,4]
输出：12
解释：选出数字 1, 3, 4 以及 4，它们的和是 12（可被 3 整除的最大和）。

## 提示
- 1 <= nums.length <= 4 * 10^4
- 1 <= nums[i] <= 10^4

## 算法思路

### 数学原理
要使数组的和能被 3 整除，有两种情况：
1. 整个数组的和本身就能被 3 整除
2. 如果和不能被 3 整除，需要移除一些最小的数字（模 3 余 1 或 2），使剩下的和能被 3 整除

### 动态规划方法
使用动态规划思想，记录所有可能的和模 3 的结果：
- `dp[0]`: 和能被 3 整除
- `dp[1]`: 和模 3 余 1
- `dp[2]`: 和模 3 余 2

遍历数组，更新这三种状态的最大和：
```
dp[(num + old_mod) % 3] = max(dp[(num + old_mod) % 3], dp[old_mod] + num)
```

### 贪心方法（最优）
1. 计算数组的总和
2. 如果总和对 3 取余是 0，直接返回总和对 3 取余
3. 否则，需要移除一些数字：
   - 如果余数是 1，移除一个模 3 余 1 的最小数
   - 如果余数是 2，移除一个模 3 余 2 的最小数（如果有多个，移除最小的两个模 3 余 1 的数）
4. 如果无法移除足够的数字，返回 0

## 复杂度分析
- 时间复杂度：O(n)，只需要遍历数组一次
- 空间复杂度：O(1)，只需要常数级别的额外空间

## 代码实现

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
var maxSumDivThree = function(nums) {
    // 初始化三种状态的和，初始化为0
    let sum0 = 0, sum1 = 0, sum2 = 0;

    for (const num of nums) {
        // 当前数字对三种状态的影响
        if (num % 3 === 0) {
            sum0 += num;
            sum1 += num;
            sum2 += num;
        } else if (num % 3 === 1) {
            sum1 += num;
            sum2 += num + sum0;
            sum0 += num;
        } else {
            sum2 += num;
            sum1 += num + sum0;
            sum0 += num;
        }
    }

    // 返回能被3整除的最大和
    return sum0;
};
```

## 优化建议
1. 使用贪心算法代替动态规划，空间复杂度更优
2. 在贪心算法中，只需记录最小模 1 和最小模 2 的数字
3. 处理边界情况，当所有数字都需要移除时返回 0

## 关键要点
1. 理解模 3 的运算规律
2. 贪心算法在处理最大和问题中的有效应用
3. 状态压缩的思想
4. 边界条件的处理
