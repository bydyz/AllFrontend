# 只使用常量额外空间（O(1) Space）

在算法和数据结构中，**"只使用常量额外空间"**（通常表述为**空间复杂度为 O(1)**）的核心定义：

> **空间复杂度 O(1)** = 算法在运行过程中额外开辟的内存空间大小是**固定的**，不随输入数据规模（n）的增大而增大。

---

## 核心原则

你只能在**输入数据本身**的基础上进行操作，不能额外申请与输入规模成正比的存储空间。

---

## 三个关键维度

### 1. 数量维度：固定数量的变量

你的额外变量数量必须固定，不能随 n 增长。

#### ✅ 正确示例：原地反转数组

```javascript
// 原地交换，只使用一个临时变量
function reverseArray(nums) {
    let left = 0;
    let right = nums.length - 1;
    while (left < right) {
        // 只需要 temp 一个临时变量
        let temp = nums[left];
        nums[left] = nums[right];
        nums[right] = temp;
        left++;
        right--;
    }
    // 额外空间：仅 temp 一个变量，固定大小
}
```

**空间复杂度**：O(1) ✅

---

#### ❌ 错误示例：创建新数组

```javascript
// 创建了与 n 等长的新数组
function duplicateArray(arr) {
    const newArr = [...arr];  // 新数组占用了 n 个空间
    return newArr;
}
```

**空间复杂度**：O(n) ❌

---

### 2. 数据结构维度：禁止"随规模增长"的容器

不能使用动态扩容的数据结构存储与 n 相关的数据。

#### ❌ 常见误区

```javascript
// 虽然看起来只用了 HashMap，但内部存储了 n 个元素
function countFrequency(nums) {
    const map = new Map();  // map 内部需要扩容
    for (const num of nums) {
        map.set(num, (map.get(num) || 0) + 1);  // 添加了 n 个键值对
    }
    return map;
}
```

**空间复杂度**：O(n) ❌（即使只有1个Map，但存储了n个元素）

---

#### ✅ 允许情况：固定大小容器

```javascript
// 使用固定大小的数组（容量是常数）
const MAX_SIZE = 1000;  // 常数
function processSmallData(arr) {
    const buffer = new Array(MAX_SIZE);  // 固定大小1000
    // 不管处理多少数据，buffer 都占用固定空间
}
```

**空间复杂度**：O(1) ✅

---

### 3. 隐形陷阱：递归调用栈

递归调用会消耗系统栈空间，这是**非常容易被忽略**的。

#### ❌ 递归遍历单链表

```javascript
function reverseList(head) {
    if (!head) return null;
    // 递归深度 = n，每层调用占固定栈空间
    // 总栈空间 = n × 常数
    const newHead = reverseList(head.next);
    head.next.next = head;  // 引用赋值
    head.next = null;
    return newHead;
}
```

**空间复杂度**：O(n) ❌（调用栈深度为 n）

---

#### ✅ 迭代实现

```javascript
function reverseList(head) {
    let prev = null;
    let curr = head;
    
    while (curr !== null) {
        const next = curr.next;  // 保存下一个节点
        curr.next = prev;        // 反转引用
        prev = curr;
        curr = next;
    }
    return prev;
}
```

**空间复杂度**：O(1) ✅（只用了3个指针变量）

---

## 记忆口诀

> **"一把螺丝刀，几个钉子"**
>
> 将你的算法想象成在一个原地（In-place）操作的工坊里工作。你手上只能拿"一把螺丝刀"和"几枚钉子"（固定的工具），不能因为待修理的零件变多了，就去搬来一整个同样大的工具箱。

---

## 实战总结

| 场景 | 空间复杂度 | 原因 |
|------|-----------|------|
| 使用固定数量的指针/临时变量 | O(1) ✅ | 固定大小 |
| 创建新数组/链表 | O(n) ❌ | 随 n 线性增长 |
| 动态扩容容器存储 n 个元素 | O(n) ❌ | 存储量与 n 成正比 |
| 递归深度为 n | O(n) ❌ | 系统栈空间 |
| 使用固定大小缓冲区 | O(1) ✅ | 容量固定 |
