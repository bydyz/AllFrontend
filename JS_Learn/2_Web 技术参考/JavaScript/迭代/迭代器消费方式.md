# JavaScript 迭代器消费方式

## 1. 显式消费

### 1.1 手动调用 next() 方法

```javascript
// 创建迭代器
const iterator = [1, 2, 3][Symbol.iterator]();

// 逐个获取值
console.log(iterator.next());  // { value: 1, done: false }
console.log(iterator.next());  // { value: 2, done: false }
console.log(iterator.next());  // { value: 3, done: false }
console.log(iterator.next());  // { value: undefined, done: true }
```

**关键点：**
- `next()` 方法返回一个对象，包含 `value`（当前值）和 `done`（是否完成）
- 调用多次返回多次值，直到返回 `{ done: true }`
- 完成（`done: true`）时，`value` 通常为 `undefined`

### 1.2 解构赋值

```javascript
const iterator = [1, 2, 3][Symbol.iterator]();

// 解构获取前几个值
const [a, b] = iterator;
console.log(a); // 1
console.log(b); // 2
console.log(iterator.next()); // { value: 3, done: false }
```

**限制：**
- 只能消费有限次
- 解构完成后迭代器仍在，可以继续调用 next()

### 1.3 for...of 循环

```javascript
const iterator = [1, 2, 3][Symbol.iterator]();

// 自动消费所有值
for (const value of iterator) {
    console.log(value); // 1, 2, 3
}

console.log(iterator.next()); // { value: undefined, done: true }
```

**特点：**
- 自动消费直到 `done: true`
- 不会抛出错误
- 可以在循环外继续使用迭代器

### 1.4 展开/展开运算符

```javascript
const iterator = [1, 2, 3][Symbol.iterator]();

// 展开为数组
const array = [...iterator];
console.log(array); // [1, 2, 3]

// 再次展开为空（已消费完毕）
const array2 = [...iterator];
console.log(array2); // []
```

**限制：**
- 必须一次性完全展开
- 不可继续使用迭代器

### 1.5 ...spread 同样有限制

```javascript
// 与解构类似
const [x, y, z] = iterator;
```

## 2. 隐式消费

### 2.1 for...of 循环（最常用）

```javascript
const iterator = [1, 2, 3][Symbol.iterator]();

for (const value of iterator) {
    // 迭代器在这里被消费
    console.log(value);
}
```

**自动处理完成状态**
- 自动检测 `done: true`
- 循环自动终止

### 2.2 while + next() 模式

```javascript
const iterator = [1, 2, 3][Symbol.iterator]();

while (true) {
    const { value, done } = iterator.next();
    if (done) break;
    console.log(value);
}
```

**完全控制消费过程**
- 可以在循环中做任何处理
- 也可以在循环中 `break` 提前终止

## 3. 方法级消费

### 3.1 数组方法

```javascript
// map
const iterator = [1, 2, 3][Symbol.iterator]();
const doubled = [...iterator].map(x => x * 2);
console.log(doubled); // [2, 4, 6]

// filter
const iterator = [1, 2, 3, 4, 5][Symbol.iterator]();
const evens = [...iterator].filter(x => x % 2 === 0);
console.log(evens); // [2, 4]

// reduce
const iterator = [1, 2, 3][Symbol.iterator()];
const sum = [...iterator].reduce((acc, val) => acc + val, 0);
console.log(sum); // 6
```

**使用场景：**
- 配合展开运算符 `[...iterator]` 将迭代器转为数组
- 然后使用数组方法处理

### 3.2 数组.from()

```javascript
const iterator = [1, 2, 3][Symbol.iterator]();

const array = Array.from(iterator);
console.log(array); // [1, 2, 3]
```

**特点：**
- 接受可迭代对象作为参数
- 也可以接受映射函数

### 3.3 Object.assign()

```javascript
const iterator = [1, 2, 3][Symbol.iterator]();

const obj = Object.assign({}, iterator);
console.log(obj); // { 0: 1, 1: 2, 2: 3, length: 3 }
```

**限制：**
- 只能转换数组类迭代器
- 忽略迭代器的 `next()` 行为

## 4. 高级场景

### 4.1 异步迭代器消费

```javascript
async function* asyncGenerator() {
    yield 'one';
    yield 'two';
    yield 'three';
}

// for await...of
for await (const value of asyncGenerator()) {
    console.log(value);
}

// 手动消费
const asyncIterator = asyncGenerator();
const { value: v1 } = await asyncIterator.next();
console.log(v1); // 'one'
```

### 4.2 管道操作

```javascript
const iterator = [1, 2, 3][Symbol.iterator]();

const result = iterator
    .next()
    .value * 2
    + iterator.next().value;

console.log(result); // 7
```

**注意事项：**
- 需要提前判断 `done` 状态
- 容易出错，不推荐

### 4.3 值传递模式

```javascript
function process(iterator) {
    const { value } = iterator.next();
    console.log('Received:', value);
}

const iterator = [1, 2, 3][Symbol.iterator()];
process(iterator); // Received: 1
```

## 5. 消费方式对比

| 消费方式 | 自动完成 | 可中断 | 保持状态 | 推荐场景 |
|---------|---------|--------|---------|---------|
| next() | ❌ | ✅ | ✅ | 精确控制 |
| 解构 | ❌ | ❌ | ❌ | 简单获取 |
| for...of | ✅ | ✅ | ✅ | **最常用** |
| 展开 | ❌ | ❌ | ❌ | 数组转换 |
| 数组方法 | ❌ | ❌ | ❌ | 数据处理 |
| Array.from | ❌ | ❌ | ❌ | 数组转换 |

## 6. 最佳实践

### 6.1 推荐使用 for...of

```javascript
// ✅ 推荐
const iterator = createIterator();
for (const value of iterator) {
    // 处理 value
}

// ❌ 不推荐
const iterator = createIterator();
while (true) {
    const { value, done } = iterator.next();
    if (done) break;
}
```

### 6.2 需要状态时手动 next()

```javascript
// ✅ 推荐手动 next()
const iterator = createIterator();
let value;
do {
    const { value: v, done } = iterator.next();
    value = v;
    if (done) break;
    // 处理
} while (true);
```

### 6.3 避免重复消费

```javascript
// ❌ 错误：多次消费
const iterator = [1, 2, 3][Symbol.iterator()];
console.log([...iterator]); // [1, 2, 3]
console.log([...iterator]); // []

// ✅ 正确：只消费一次
const iterator = [1, 2, 3][Symbol.iterator()];
const result = [...iterator];
console.log(result); // [1, 2, 3]
// 不能再消费
```

## 7. 实际应用示例

### 7.1 模拟数据库查询

```javascript
function* mockDatabase() {
    console.log('连接数据库...');
    yield 1;
    yield 2;
    yield 3;
    console.log('关闭连接');
}

const iterator = mockDatabase();
for (const value of iterator) {
    console.log('查询结果:', value);
}
```

### 7.2 流式处理

```javascript
async function* streamData() {
    // 模拟从网络获取数据
    yield 'data1';
    await new Promise(r => setTimeout(r, 1000));
    yield 'data2';
    await new Promise(r => setTimeout(r, 1000));
    yield 'data3';
}

async function processStream() {
    for await (const chunk of streamData()) {
        console.log('处理:', chunk);
    }
}

processStream();
```

---

## 8. 总结

1. **核心方法**：`next()` 是唯一显式消费的方法
2. **推荐方式**：`for...of` 是最简洁、安全的消费方式
3. **状态保持**：手动 `next()` 可以保持迭代器状态
4. **注意事项**：避免重复消费，注意迭代器的完成状态
5. **高级用法**：异步迭代器配合 `for await...of` 用于流式数据处理
