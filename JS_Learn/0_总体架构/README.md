# 面向开发者的 Web 技术

> 开放的 Web 为开发者提供了巨大的机遇，为了充分利用这些技术，你需要知道如何使用它们。

---

## 面向 Web 开发者的文档

| 类别 | 说明 |
|:---|:---|
| [Web 开发者指南](https://developer.mozilla.org/zh-CN/docs/MDN/Guides) | 提供实用的操作方法，帮助你使用 Web 技术实现目标 |
| [面向 Web 开发者的教程](https://developer.mozilla.org/zh-CN/docs/MDN/Tutorials) | 一步步学习 HTML、CSS、JavaScript 和 Web API |

| [隐私](https://developer.mozilla.org/zh-CN/docs/Web/Privacy) | 保护用户的个人数据 |
| [安全](https://developer.mozilla.org/zh-CN/docs/Web/Security) | 保护用户免受数据泄露、跨站脚本等攻击 |

## Web 技术参考

### 核心技术

| 技术 | 说明 | 文档 |
|:---|:---|:---|
| **HTML** | 用基本构建块创建 Web 文档和应用 | [MDN HTML](https://developer.mozilla.org/zh-CN/docs/Web/HTML) |
| **CSS** | 用层叠样式表描述 Web 文档和应用的外观 | [MDN CSS](https://developer.mozilla.org/zh-CN/docs/Web/CSS) |
| **JavaScript** | Web 的原生编程语言 | [MDN JavaScript](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript) |
| **Web API** | 用 JavaScript 编程 API 构建 Web 应用 | [MDN Web API](https://developer.mozilla.org/zh-CN/docs/Web/API) |
| **WebAssembly** | 在 Web 上运行 C、C++、Rust、Go 等语言编写的程序 | [MDN WebAssembly](https://developer.mozilla.org/zh-CN/docs/WebAssembly) |

### Web 核心概念

| 概念 | 说明 | 文档 |
|:---|:---|:---|
| [事件](https://developer.mozilla.org/zh-CN/docs/Web/API/Document_Object_Model/Events) | 可响应的内容：页面加载、按键、表单提交等 | DOM Events |
| [HTTP](https://developer.mozilla.org/zh-CN/docs/Web/HTTP) | 获取资源、发送数据的基础互联网协议 | MDN HTTP |
| [媒体](https://developer.mozilla.org/zh-CN/docs/Web/Media) | 嵌入和流式传输视频、音频和图像内容 | MDN Media |
| [URI](https://developer.mozilla.org/zh-CN/docs/Web/URI) | 统一资源标识符，用于标识各种资源 | MDN URI |

### 图形与显示

| 技术 | 说明 | 文档 |
|:---|:---|:---|
| [SVG](https://developer.mozilla.org/zh-CN/docs/Web/SVG) | 可缩放矢量图形，创建可平滑缩放至任意尺寸的图像 | MDN SVG |
| [MathML](https://developer.mozilla.org/zh-CN/docs/Web/MathML) | 在 Web 上显示复杂的数学符号 | MDN MathML |

### 扩展与应用

| 技术 | 说明 | 文档 |
|:---|:---|:---|
| [WebDriver](https://developer.mozilla.org/zh-CN/docs/Web/WebDriver) | 浏览器自动化机制，用于跨浏览器测试 | MDN WebDriver |
| [Web 扩展](https://developer.mozilla.org/zh-CN/docs/Mozilla/Add-ons/WebExtensions) | 为浏览器用户提供增强功能 | MDN WebExtensions |
| [Web 应用清单](https://developer.mozilla.org/zh-CN/docs/Web/Progressive_web_apps/Manifest) | 将 Web 应用安装到设备主屏幕 | MDN PWA Manifest |
| [渐进式 Web 应用（PWA）](https://developer.mozilla.org/zh-CN/docs/Web/Progressive_web_apps) | 提供类似原生移动应用的用户体验 | MDN PWA |
| [OpenSearch](https://developer.mozilla.org/zh-CN/docs/Web/XML/Guides/OpenSearch) | 描述网站的搜索引擎，供浏览器使用 | MDN OpenSearch |

### XML 相关

| 技术 | 说明 | 文档 |
|:---|:---|:---|
| [XML](https://developer.mozilla.org/zh-CN/docs/Web/XML) | 可扩展标记语言，可由 DOM 严格序列化 | MDN XML |
| [XSLT](https://developer.mozilla.org/zh-CN/docs/Web/XML/XSLT) | 基于 XML 的语言，用于 XML 文档转换 | MDN XSLT |
| [XPath](https://developer.mozilla.org/zh-CN/docs/Web/XML/XPath) | 灵活定位 XML 文档不同部分的方法 | MDN XPath |
| [EXSLT](https://developer.mozilla.org/en-US/docs/Web/XML/EXSLT) | XSLT 的扩展集合 | MDN EXSLT |
