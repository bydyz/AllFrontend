方案6：系统级媒体查询

自动跟随系统

当前系统偏好检测：

prefers-color-scheme: dark → 跟随系统暗色模式

prefers-color-scheme: light → 跟随系统亮色模式

no-preference → 无偏好，使用默认

原理：

使用 CSS @media 查询检测操作系统的颜色方案偏好，自动应用对应主题。

所有可用媒体查询：

/* 暗色模式 - 检测系统是否使用暗色主题 */
@media (prefers-color-scheme: dark) { }

/* 亮色模式 - 检测系统是否使用亮色主题 */
@media (prefers-color-scheme: light) { }

/* 减少动画（无障碍）- 用户偏好减少动画效果 */
@media (prefers-reduced-motion: reduce) { }

/* 弱色偏好 - 用户偏好更多对比度 */
@media (prefers-contrast: more) { }

/* 高对比度 - 系统已启用高对比度模式 */
@media (prefers-contrast: less) { }

特点：

  • 完全依赖操作系统设置
  • 零 JavaScript 代码
  • 用户体验一致（与应用保持同步）
  • 无法手动覆盖（用户需更改系统设置）
  • 适合作为默认策略，配合用户手动切换

💡 提示：在系统设置中更改亮色/暗色模式即可看到效果。
