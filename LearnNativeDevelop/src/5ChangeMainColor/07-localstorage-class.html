方案7：localStorage持久化 + Class

当前 localStorage 值：

原理：

将用户的主题偏好存储在 localStorage，页面加载时读取并应用，支持三种模式。

核心代码：

// 保存偏好到 localStorage
localStorage.setItem('theme', 'dark');

// 页面加载时读取并应用
const saved = localStorage.getItem('theme');
if (saved === 'dark') {
  document.documentElement.classList.add('dark');
}

// 监听系统主题变化（当选择"跟随系统"时）
const mq = window.matchMedia('(prefers-color-scheme: dark)');
mq.addEventListener('change', handleSystemChange);

特点：

  • 用户选择持久化保存
  • 刷新页面保持主题不变
  • 支持三种模式：亮色、暗色、跟随系统
  • 组合多种方案的最佳实践
  • 主流网站普遍采用此方案
