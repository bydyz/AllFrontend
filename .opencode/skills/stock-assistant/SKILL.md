# 股票投资辅助工具 (Stock Assistant)

本 skill 专注于收集可能影响A股市场的政策信息和市场消息，只收集调用时间之前的信息。

## 核心能力

### 1. 政策信息搜索

使用 websearch 搜索调用时间之前的影响股市的政策和消息：

**搜索范围**：
- 证监会相关政策（IPO、减持、退市、制度改革等）
- 央行/金融政策（利率、LPR、降准等）
- 宏观经济数据发布（CPI/PPI、GDP、PMI等）
- 行业政策（新能源、半导体、医药等）
- 中央重要会议/表态
- 国际市场动态（美联储加息、中美关系等）

**搜索关键词模板**：
```
# 最近一周政策
"A股 政策 证监会 {}" (使用调用时间的年份)
"央行 降准 LPR {}" 
"中央经济工作会议 {}"
"证监会 IPO {}"
"国务院 新能源 {}"

# 行业政策
"半导体 政策 {}"
"医药 集采 {}"
"房地产 政策 {}"

# 市场动态
"A股 走势 {}"
"降准 股市 影响 {}"
```

### 2. 消息整合

将搜索到的政策信息按以下维度整理：
- **宏观政策**：货币、财政、汇率等
- **监管政策**：证监会、交易所相关
- **行业政策**：各部委发布的行业政策
- **国际因素**：美联储、国际局势等

## 使用方式

当用户需要了解最近有什么可能影响股市的政策或消息时：
1. 获取当前调用时间（年/月/日/时/分）
2. 使用 websearch 搜索相关内容
3. 整理并输出信息到 `output/{日期}-{时分}.md` 文件

**输出文档命名规则**：`{YYYY-MM-DD}-{HHmm}.md`
例如：`2026-04-18-1655.md`

## 输出格式

整理搜索到的信息，按以下格式输出：

```markdown
# 可能影响股市的政策和消息 - {date}

## 宏观政策
- [相关政策1]
- [相关政策2]

## 监管政策
- [相关政策1]

## 行业政策
- [相关政策1]

## 国际因素
- [相关信息1]
```

## 注意事项

1. 只收集调用时间之前的信息，不要使用未来日期
2. 投资风险：本工具仅供参考，不构成投资建议
3. 建议多个信息源交叉验证
