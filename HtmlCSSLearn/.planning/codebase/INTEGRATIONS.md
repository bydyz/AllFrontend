# External Integrations

## No External APIs

This project is a self-contained HTML/CSS learning repository with no external API integrations.

## No Databases

No database connections or backend services.

## No Auth Providers

No authentication, OAuth, or identity providers.

## No Webhooks

No webhook integrations or external event listeners.

## No Third-party Services

The only dependencies are local development tools:
- **Vite** - Build tool and dev server
- **Vue 3** - Frontend framework
- **Tailwind CSS 4** - Utility-first CSS framework
- **SCSS** - CSS preprocessor

## No Analytics or Tracking

No external analytics, monitoring, or tracking services.

## No Email Services

No email sending or SMTP integrations.

## No Payment Gateways

No payment processing or checkout services.

## No Social Media APIs

No social media platform integrations.

## Local File System Access

- Asset imports use relative paths
- No file system operations beyond standard Vue component imports
