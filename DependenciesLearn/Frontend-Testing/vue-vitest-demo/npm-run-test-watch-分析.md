# npm run test:watch 命令分析

## 命令说明

`npm run test:watch` 是一个用于监视模式运行测试的命令，对应的脚本是 `vitest`。

### 命令作用
- **vitest**：不带 `--run` 参数，启动 Vitest 的监视模式（watch mode）
- **监视模式**：持续运行测试，当文件变化时自动重新运行相关测试

### 与 `npm run test` 的区别
| 特性 | npm run test | npm run test:watch |
|------|--------------|-------------------|
| 运行方式 | 单次运行 | 持续监视 |
| 文件变化 | 不响应 | 自动重新测试 |
| 退出方式 | 运行完成自动退出 | 需手动退出 (Ctrl+C) |
| 适用场景 | CI/CD、部署前验证 | 开发过程实时反馈 |

   - 错误：`vi.spyOn()` 无法找到监视对象

2. **Counter.test.js** - 事件测试失败（2个）
   - 错误：期望的 `update` 事件未触发

3. **useTodoList.test.js** - 待办事项测试失败（2个）
   - 错误：对象比较问题

### 监视模式特性
- 首次运行会执行所有测试
- 后续只运行变化文件相关的测试
- 支持文件过滤和模式匹配

## 结果分析

### 测试通过率
- **通过率**：154/159 = **96.86%**
- **失败率**：5/159 = **3.14%**

### 监视模式的优势
1. **实时反馈**：修改代码后立即看到测试结果
2. **增量测试**：只运行受影响的测试，提高效率
3. **开发体验**：无需反复手动执行测试命令

### 使用场景
- **开发阶段**：编写新功能时实时验证
- **调试测试**：修复失败测试时快速迭代
- **重构代码**：确保改动不破坏现有功能

### 注意事项
1. 监视模式会持续占用终端
2. 某些 IDE 的文件保存可能触发频繁测试
3. 大型项目可能需要配置忽略目录

## 常用快捷键
在监视模式下，可以使用以下快捷键：
- `a` - 运行所有测试
- `f` - 运行失败的测试
- `o` - 只运行匹配的文件
- `p` - 按模式过滤文件名
- `t` - 按测试名过滤
- `q` - 退出监视模式
