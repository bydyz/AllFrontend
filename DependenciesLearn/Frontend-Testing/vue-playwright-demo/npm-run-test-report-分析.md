# npm run report 命令分析

## 命令说明

`npm run report` 是一个用于查看测试报告的命令，对应的脚本是 `npx playwright show-report`。

### 命令作用
- **npx playwright show-report**：打开 Playwright 测试报告界面
- **查看报告**：查看测试执行结果、截图、追踪信息

### 报告类型
- **HTML 报告**：交互式 Web 报告
- **控制台报告**：命令行输出
- **JSON 报告**：结构化数据

- **分享测试结果**：向团队展示测试结果

## 报告查看指南

### 1. 启动报告

```bash

```

- 点击"追踪"标签查看详细日志

### 5. 筛选测试

- 按状态筛选：通过、失败、跳过
- 按文件筛选：查看特定文件的测试
- 按关键词筛选：搜索特定测试

## 报告配置

### 1. 报告器配置

```javascript
// playwright.config.js
export default defineConfig({
  reporter: [
    ['html', { open: 'never' }],  // HTML 报告
    ['list']                       // 控制台报告
  ]
})
```

### 2. 报告输出目录

```javascript
// 默认报告目录
test-results/

// 自定义报告目录
reporter: [
  ['html', { outputFolder: 'my-report' }]
]
```

### 3. 报告选项

```javascript
// HTML 报告选项
['html', {
  open: 'never',           // 是否自动打开
  outputFolder: 'report',  // 输出目录
  attachments: true        // 是否包含附件
}]
```

## 常见问题

### 报告无法打开
**问题**：执行 `npm run report` 后报告界面未显示。

**解决**：
1. 检查是否执行过测试
2. 检查报告输出目录
3. 手动指定报告路径

### 截图不显示
**问题**：报告中截图为空。

**解决**：
1. 检查截图配置
2. 确保测试失败时截图
3. 检查截图文件路径

### 追踪信息缺失
**问题**：报告中没有追踪信息。

**解决**：
1. 检查 trace 配置
2. 确保配置为 `on-first-retry`
3. 重新运行失败测试
