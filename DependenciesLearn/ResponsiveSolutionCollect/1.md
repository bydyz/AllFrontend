# 响应式设计开源项目精选

以下是一些采用了响应式设计的开源项目，覆盖了从个人作品集到企业官网等多种类型。你可以参考它们的实现方式，也可以直接 fork 来学习。

---

## 🗂️ 项目精选

| 项目名称 | 项目类型 | 技术栈 | 响应式实现亮点 |
|:---------|:---------|:-------|:---------------|
| [ITUSI - 现代AI企业网站](https://github.com/ItusiAI/Modern-AI-Corporate-Website) | 企业官网 | Next.js 15, Tailwind CSS, Radix UI | 基于 Next.js 和 Tailwind CSS 构建，完美适配各种设备 |
| [沐辰个人主页](https://github.com/mcwlgzs/mc-homepage) | 个人品牌页 | Tailwind CSS, Particles.js, Typed.js | "完全响应式"，适配从手机到桌面的各种设备 |
| [BusinessGROW](https://github.com/Deepanshu-K991/mobile-friendly-website) | 企业展示页 | HTML5, CSS3, JavaScript | 移动优先 (Mobile-First)，在 768px(平板) 和 480px(手机) 设有断点 |
| [导航站 navpro](https://github.com/pusws/navpro) | 导航站 | 纯 HTML/CSS/JavaScript | 明确标注"响应式设计 - 完美适配各种设备尺寸" |
| [vhAstro-Theme](https://github.com/uxiaohan/vhAstro-Theme) | 博客主题 | Astro | 主打"简洁的响应式设计" |
| [Odoo 单页网站](https://github.com/jeromeDH/odoo-exercise-JDH) | 品牌展示页 | Bootstrap 5.3.8, SCSS | 基于 Bootstrap 5.3.8 的网格系统和响应式工具，实现移动优先的完全响应式布局 |
| [个人作品集 Portfolio](https://github.com/jojin1709/Personal-Portfolio-Website) | 个人作品集 | HTML, CSS, JavaScript | "完全响应式"，在桌面、平板和移动设备上都能无缝工作 |
| [Bento Grid 布局页面](https://github.com/CristinaOsorio/bento-grid-solution) | 布局演示 | HTML, CSS | 专注于实现一个能在移动、平板和桌面屏幕间平滑适配的 Bento 网格布局 |
| [管理后台模板 ADMIN-DASHBOARD](https://github.com/DINESHTM07/ADMIN-DASHBOARD) | 管理后台 | HTML, CSS, JavaScript | 一个具有"响应式设计"的现代化管理面板模板 |
| [响应式新闻网站 Demo](https://github.com/LaohanDesign/test2025) | 新闻网站 | HTML, CSS | 一个简单的响应式新闻网站示例，强调语义化和标准化的命名 |

## 🚀 如何快速上手

### 在线预览

许多项目在 README 中提供了在线预览链接（例如"沐辰个人主页"），你可以直接体验其响应式效果。

### 本地运行

| 项目类型 | 运行方式 |
|:---------|:---------|
| 纯静态项目 | `git clone` 下载后，直接在浏览器中打开 `index.html` |
| Node.js 项目 | `npm install` → `npm run dev` |

## 🔍 如何找到更多项目

### GitHub 搜索关键词

- `responsive design`
- `responsive website`
- `mobile-first`
- `Bootstrap responsive`
- `Tailwind responsive`

### 设计灵感平台

- **即时设计** - 提供设计案例和可直接使用的 UI 资源
- **UI中国** - 展示响应式布局的视觉呈现
