# DPI 与 PPI 详解

## 基本定义

### PPI (Pixels Per Inch)
**像素密度**，表示每英寸屏幕上的像素数量。

```
PPI = √(水平像素² + 垂直像素²) / 屏幕对角线尺寸(英寸)
```

**示例计算：**
- iPhone 14: 1170 × 2532 像素，6.1 英寸
- PPI = √(1170² + 2532²) / 6.1 ≈ 460 PPI

### DPI (Dots Per Inch)
**每英寸点数**，最初用于打印领域，表示打印机每英寸能打印的墨点数量。

```
DPI = 总点数 / 打印尺寸(英寸)
```

**示例：**
- 300 DPI 打印机：每英寸打印 300 个墨点
- 72 DPI 屏幕：每英寸显示 72 个像素点

## 核心区别

| 特性 | PPI | DPI |
|------|-----|-----|
| **应用领域** | 屏幕显示 | 打印输出 |
| **衡量对象** | 像素密度 | 墨点/物理点密度 |
| **单位** | 像素/英寸 | 点/英寸 |
| **影响范围** | 屏幕清晰度、UI 适配 | 打印质量、文档精度 |
| **可变性** | 固定硬件属性 | 可调节参数 |

## 在前端开发中的应用

### 1. 设备像素比 (Device Pixel Ratio)
```javascript
// 获取设备像素比
const dpr = window.devicePixelRatio || 1;

// DPR 物理像素 = CSS 像素 × DPR
// 例：DPR=2 时，1 CSS 像素 = 2×2 = 4 物理像素
```

### 2. 高清图片适配
```html
<!-- 根据 DPR 选择合适分辨率的图片 -->
<img src="image@1x.jpg" 
     srcset="image@1x.jpg 1x, image@2x.jpg 2x, image@3x.jpg 3x"
     alt="响应式图片">
```

### 3. CSS 像素与物理像素
```
CSS 像素 = 物理像素 / DPR
例：iPhone 14 (DPR=3)
  - 物理宽度：1170px
  - CSS 宽度：1170 / 3 = 390px
```

## 常见设备 PPI 参考

| 设备类型 | PPI 范围 | 说明 |
|----------|----------|------|
| 标准显示器 | 90-110 | 普通桌面显示器 |
| 笔记本电脑 | 110-160 | 视网膜屏出现前 |
| Retina MacBook | 220+ | 苹果视网膜屏幕 |
| 智能手机 | 300-500+ | 高清移动设备 |
| 平板电脑 | 200-300 | iPad 等设备 |

## 实际开发建议

### 1. 图片资源准备
- 1x 图片：基础分辨率
- 2x 图片：2倍分辨率（Retina 屏幕）
- 3x 图片：3倍分辨率（高端手机）

### 2. 字体渲染优化
```css
/* 针对高 PPI 屏幕优化字体 */
body {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  text-rendering: optimizeLegibility;
}
```

### 3. 边框和阴影处理
```css
/* 高 PPI 屏幕下保持清晰 */
.border {
  border: 0.5px solid #ccc; /* 某些设备需要亚像素渲染 */
}

.shadow {
  box-shadow: 0 1px 2px rgba(0,0,0,0.1); /* 避免模糊 */
}
```

## 常见误区

1. **DPI 不等于 PPI**
   - DPI 用于打印，PPI 用于屏幕
   - 日常使用中常被混用，但概念不同

2. **高 PPI 不一定更清晰**
   - 还取决于屏幕尺寸、观看距离、内容类型

3. **CSS 像素与物理像素不同**
   - CSS 像素是逻辑单位，物理像素是实际硬件点

## 总结

- **PPI**：衡量屏幕像素密度，影响 UI 适配和图片清晰度
- **DPI**：衡量打印点密度，影响打印质量和文档精度
- 在前端开发中，主要关注 **PPI** 和 **设备像素比 (DPR)**
- 理解这些概念有助于创建适配各种设备的响应式界面
