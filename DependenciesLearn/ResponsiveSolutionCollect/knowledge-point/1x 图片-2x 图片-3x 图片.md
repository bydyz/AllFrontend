# 图片资源

- 1x 图片：基础分辨率
- 2x 图片：2倍分辨率（Retina 屏幕）
- 3x 图片：3倍分辨率（高端手机）

在图片领域，“基础分辨率”、“2倍分辨率”和“3倍分辨率”，核心指的是图片的宽高像素数（边长）按倍数放大，而不是总面积放大。



# 核心算法（边长翻倍，面积翻4倍/9倍）

1. 基础分辨率（1x）：原始尺寸。假设一张图是 1000px × 1000px。
2. 2倍分辨率（2x）：宽和高各乘以2。尺寸变为 2000px × 2000px。注意，总像素数（面积）变成了原来的 4倍（不是2倍）。
3. 3倍分辨率（3x）：宽和高各乘以3。尺寸变为 3000px × 3000px。总像素数变成了原来的 9倍（不是3倍）。



# 在手机/电脑界面（UI显示）上：物理尺寸一样大

假设设计师在手机上放一个图标，规定它在屏幕上必须显示为 1厘米 × 1厘米。

  * 基础图（1000px）：在1厘米里塞进1000个像素点。
  * 2倍图（2000px）：在同样1厘米里塞进2000个像素点。
  * 3倍图（3000px）：在同样1厘米里塞进3000个像素点。

结果：三者显示出来的大小完全一样（都是1厘米），但2倍图比基础图细腻，3倍图最细腻（看不到锯齿）。这就是苹果视网膜屏的原理。



# 在图片查看器/浏览器（100%缩放）上：物理尺寸不一样大

如果你把这三张图下载到电脑，用Windows照片查看器或PS打开，并且缩放比例都设为 100%（即1个像素对应屏幕1个像素）：

  * 基础图（1000px）：占满屏幕宽度的约一半（假设屏幕宽1920px）。
  * 2倍图（2000px）：比屏幕还宽，你需要拖动滚动条才能看全。
  * 3倍图（3000px）：巨大无比，要滚动很多下才能看全。

结果：此时它们显示的物理大小完全不同（3倍图最大），但清晰度一样（因为都是100%原像素展示）。



# 这三张图在“图片内容”（构图、色彩、人物动作）上完全一致，唯一的区别就是承载这个内容的“画布”像素格子数量不同：

* 1000×1000 = 总共有 100万 个像素点来拼成这张图
* 2000×2000 = 总共有 400万 个像素点来拼成这张图（细节更丰富）
* 3000×3000 = 总共有 900万 个像素点来拼成这张图（细节最丰富）

这就好比用同样一张照片，分别用100万个马赛克小方块、400万个马赛克小方块和900万个马赛克小方块去拼贴它——小方块越多，单个方块越小，画面就越细腻顺滑。

你只需要记住这个核心结论就够用了。在实际使用中，如果你要打印大海报，就用3000px的；如果只是发微信朋友圈或做网页缩略图，用1000px的就完全足够（太大反而加载慢）。
