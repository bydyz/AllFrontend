## 九、主要内容区域宽度设置

### 核心原则

1. **内容宽度上限**：主内容区域最大宽度一般不超过 **1200px**
2. **两侧留白**：大屏时两侧必须留白，避免内容拉伸过长影响阅读
3. **居中对齐**：内容区域始终水平居中

### 常见布局宽度参考

| 屏幕类型 | 视口宽度 | 内容区宽度 | 两侧留白 | 说明 |
|---------|---------|-----------|---------|------|
| 手机竖屏 | 360-414px | 100% | 16-20px | 全宽，留内边距 |
| 平板竖屏 | 768px | 100% | 24-32px | 全宽，留内边距 |
| 平板横屏 | 1024px | 90%-95% | 自动 | 略小于视口 |
| 小笔记本 | 1280px | 960-1100px | 自动 | 开始限制最大宽度 |
| 桌面 | 1440px | 1100-1200px | 自动 | 标准内容宽度 |
| 大桌面/2K | 1920px | 1200px | 自动 | 固定最大宽度 |
| 4K | 3840px | 1200px | 自动 | 固定最大宽度，两侧大量留白 |

### CSS 实现方案

#### 方案一：基础响应式容器

```css
.container {
  width: 100%;
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 16px;
  box-sizing: border-box;
}

/* 平板及以上 */
@media (min-width: 768px) {
  .container {
    padding: 0 24px;
  }
}

/* 桌面 */
@media (min-width: 1280px) {
  .container {
    padding: 0 32px;
  }
}
```

#### 方案二：分断点宽度控制

```css
.main-content {
  width: 100%;
  margin: 0 auto;
}

/* 手机：全宽，小内边距 */
@media (max-width: 767px) {
  .main-content {
    padding: 0 16px;
  }
}

/* 平板：全宽，中内边距 */
@media (min-width: 768px) and (max-width: 1023px) {
  .main-content {
    padding: 0 24px;
    max-width: 720px;
  }
}

/* 小桌面：限制宽度 */
@media (min-width: 1024px) and (max-width: 1439px) {
  .main-content {
    max-width: 960px;
  }
}

/* 桌面：标准宽度 */
@media (min-width: 1440px) {
  .main-content {
    max-width: 1200px;
  }
}
```

#### 方案三：使用 CSS 变量统一管理

```css
:root {
  /* 内容宽度 */
  --content-width-sm: 100%;
  --content-width-md: 720px;
  --content-width-lg: 960px;
  --content-width-xl: 1200px;
  
  /* 内边距 */
  --spacing-xs: 16px;
  --spacing-sm: 24px;
  --spacing-md: 32px;
  --spacing-lg: 48px;
}

.container {
  width: 100%;
  max-width: var(--content-width-xl);
  margin: 0 auto;
  padding: 0 var(--spacing-xs);
  box-sizing: border-box;
}

@media (min-width: 768px) {
  .container {
    padding: 0 var(--spacing-sm);
  }
}

@media (min-width: 1440px) {
  .container {
    padding: 0 var(--spacing-md);
  }
}
```

### 常见布局模式宽度

#### 单列居中（文章/博客）

```css
.article {
  max-width: 720px;
  margin: 0 auto;
  padding: 0 20px;
}

@media (min-width: 768px) {
  .article {
    padding: 0 40px;
  }
}
```

#### 两栏布局（侧边栏 + 主内容）

```css
.layout {
  display: flex;
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 16px;
  gap: 24px;
}

.sidebar {
  width: 240px;
  flex-shrink: 0;
}

.main {
  flex: 1;
  min-width: 0;
}

/* 平板：隐藏侧边栏或改为抽屉 */
@media (max-width: 1023px) {
  .sidebar {
    display: none;
  }
}
```

#### 三栏布局（后台管理）

```css
.admin-layout {
  display: flex;
  min-height: 100vh;
}

.menu {
  width: 200px;
  flex-shrink: 0;
}

.content-area {
  flex: 1;
  padding: 24px;
  overflow: auto;
}

.content {
  max-width: 1200px;
}

/* 折叠侧边栏 */
@media (max-width: 768px) {
  .menu {
    position: fixed;
    left: -200px;
    z-index: 100;
    transition: left 0.3s;
  }
  
  .menu.open {
    left: 0;
  }
}
```
