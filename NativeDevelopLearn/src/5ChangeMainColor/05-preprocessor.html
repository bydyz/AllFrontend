方案5：CSS预处理器变量 + 构建工具

SCSS / Sass 
// _variables.scss
// 预处理器变量 - 定义主题颜色
$bg-light: #ffffff;
$bg-dark: #1a1a1a;

// Mixin - 可复用的主题样式块
@mixin theme($is-dark: false) {
  @if $is-dark {
    --bg: $bg-dark;
    --text: #e0e0e0;
  } @else {
    --bg: $bg-light;
    --text: #333333;
  }
}

// 使用时通过构建工具注入变量值
:root { @include theme(false); }
.dark { @include theme(true); }
Less 
// variables.less
// Less 变量
@bg-light: #ffffff;
@bg-dark: #1a1a1a;

// Less 混合（Mixin）带有守卫条件
.theme(@is-dark) when (@is-dark = true) {
  --bg: @bg-dark;
  --text: #e0e0e0;
}
.theme(@is-dark) when (@is-dark = false) {
  --bg: @bg-light;
  --text: #333333;
}
构建时动态切换示例 (PostCSS) 
// postcss.config.js
module.exports = {
  plugins: {
    // postcss-darkmode 插件
    // 可以在构建时生成暗色主题变体
    'postcss-darkmode': {
      darkSelector: '.dark',
      darkValue: 'dark'
    }
  }
};

特点：

  • 构建时生成不同主题的 CSS 文件
  • 运行时切换需要加载不同文件或覆盖变量
  • 适合多主题打包场景
  • 配合 PostCSS 插件可实现运行时切换
