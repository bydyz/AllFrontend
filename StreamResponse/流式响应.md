# 流式响应

## 浏览器如何解析流式数据？

浏览器处理流式数据的方式取决于具体的API：

### Fetch + ReadableStream

```js
const response = await fetch('/stream');
const reader = response.body.getReader();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  // value 是 Uint8Array，每到达一个 chunk 就会触发一次
  console.log('收到数据块:', value);
}
```

### Server-Sent Events (SSE)

```js
const eventSource = new EventSource('/stream');
eventSource.onmessage = (e) => {
  // 每收到一条消息就触发一次
  console.log(e.data);
};
```

### 关键点

1. **不是第一份数据就开始完整解析**：流数据是逐步到达的，每收到一个chunk（数据块）就会触发一次读取

2. **按块处理**：浏览器接收到底层TCP数据后，通过`ReadableStream`或SSE事件将数据暴露给JS，JS可以逐块处理

3. **流式响应的特点**：
   - `Transfer-Encoding: chunked` 分块传输
   - 每个chunk有固定格式：`[chunk大小]\r\n[数据]\r\n`
   - 浏览器底层解析HTTP响应，遇到`\r\n\r\n`开始解析头部，之后每个chunk按大小分割

4. **SSE特殊处理**：服务器发送的数据按`\n\n`分割为独立事件，每个事件单独触发`onmessage`

**结论**：是的，接收到第一个chunk后就可以开始处理，不必等待全部数据到达。

## 流式响应的多种实现方式

流式响应有多种实现方式：

### 1. Fetch + ReadableStream

最通用的流式处理方式，可处理任意格式的流。

### 2. Server-Sent Events (SSE)

基于HTTP的单向流，专为服务器推送设计，自动解析`data:`字段，自动重连，适合简单场景。

### 3. WebSocket

双向通信，不受同源限制。

### 4. Web Streams API

底层API，包含 ReadableStream、WritableStream、TransformStream。

### 总结

| API | 特点 |
|-----|------|
| Fetch + ReadableStream | 通用，可处理任意格式的流 |
| SSE | 自动解析data字段，自动重连，适合简单场景 |
| WebSocket | 全双工，不受同源限制 |

"流式响应"是一个概念，**Fetch + ReadableStream** 是实现这个概念的主要手段之一。
